# 🐾 Animal Detection using YOLOv10

This project demonstrates an **end-to-end Animal Detection system** built using **YOLOv10** and a dataset downloaded from **Roboflow**.  
It covers the complete pipeline from dataset preparation to model training, evaluation, and inference visualization.

---

## 🚀 Project Highlights

- Download and manage datasets using **Roboflow API**
- YOLO-format annotation handling
- Visualize bounding boxes on training images
- Train a **YOLOv10** object detection model
- Apply advanced data augmentation techniques
- Plot training losses (Box Loss, Class Loss, DFL Loss)
- Run inference and visualize predictions on test images

---

## 🧠 Dataset Classes

The model is trained to detect the following classes:

- Cat
- Dog
- Cow
- Horse
- Goat
- Chicken
- Fox
- Person
- Racoon
- Skunk

## 📂 Project Workflow

1. Install required libraries  
2. Download dataset from Roboflow  
3. Prepare YOLO-formatted dataset  
4. Visualize training annotations  
5. Train YOLOv10 with data augmentation  
6. Evaluate model performance  
7. Visualize predictions on test images

The trained model successfully detects multiple animals in real-world images with accurate bounding boxes and class predictions.
